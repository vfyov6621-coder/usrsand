# sandusr — Telegram Userbot v3.0

Модульный Telegram юзербот на базе **Pyrofork** с веб-панелью управления, системой модулей с горячей перезагрузкой и поддержкой плагинов-аддонов. Все команды на русском языке с сокращённым синтаксисом через префикс `-`.

## Возможности

- **Модульная архитектура** — каждый модуль в отдельной папке (`scripts/<имя>/`) с `meta.json` + `main.py`. Загрузка, выгрузка и перезагрузка без перезапуска бота
- **Система аддонов** — дополнительные плагины внутри модуля (`scripts/<имя>/addons/`), подключаются автоматически
- **Веб-панель** — Flask-дашборд на порту 8080 с управлением модулями, логами в реальном времени, автозагрузкой и списком команд
- **Автозагрузка** — настройка через `scripts/autostart.json` или переключатели в веб-панели: все модули либо только выбранные
- **Windows-установщик** — `.exe` с обоями, автоматической установкой зависимостей, созданием `.env` и ярлыков, встроенным автообновлением бота и самого установщика с GitHub Releases
- **Автодиагностика** — проверка DNS, TCP-соединения с Telegram DC, прокси, синхронизация системных часов через NTP при старте
- **Поддержка прокси** — SOCKS5/SOCKS4/HTTP через переменную `PROXY` в `.env`
- **Принудительный IPv4** — для VPN-подключений с неработающим IPv6

## Установка

### Вручную

```bash
git clone https://github.com/vfyov6621-coder/usrsand.git
cd usrsand
pip install -r requirements.txt
```

Создай файл `.env` в корне проекта:

```env
API_ID=your_api_id
API_HASH=your_api_hash
PHONE=+79991234567
# или вместо PHONE:
SESSION_STRING=your_session_string
```

Опционально:

```env
# Прокси (если Telegram заблокирован)
PROXY=socks5://user:pass@host:port
# Отключить принудительный IPv4
FORCE_IPV4=0
# Порт веб-панели (по умолчанию 8080)
PORT=8080
```

Запуск:

```bash
python main.py
```

### Windows-установщик (.exe)

Скачай `sandusr-installer.exe` из [Releases](https://github.com/vfyov6621-coder/usrsand/releases). Установщик автоматически клонирует репозиторий, устанавливает зависимости через `pip`, создаёт `.env` и ярлыки. Во вкладке «Обновления» можно проверять обновления вручную или настроить автообновление с произвольным интервалом (формат `ЧЧ:ММ`).

## Встроенные команды

Эти команды зарегистрированы напрямую в `main.py` и всегда доступны:

| Команда | Описание |
|---------|----------|
| `-меню` | Интерактивное меню бота с inline-кнопками (пинг, инфо, владелец) |
| `-мф` | Установить фото для меню (ответ на фото/стикер) |
| `-рн от до` | Случайное число с неuniformным распределением (каждое число имеет разный шанс) |
| `-лм` | Управление модулями |

### Управление модулями (`-лм`)

| Команда | Описание |
|---------|----------|
| `-лм` / `-лм список` | Список всех модулей (загруженных и доступных) |
| `-лм загрузить <name>` | Загрузить модуль |
| `-лм выгрузить <name>` | Выгрузить модуль |
| `-лм перезагрузить <name>` | Перезагрузить модуль (unload + load) |
| `-лм инфо <name>` | Информация о модуле (размер, строки, команды, аддоны) |

## Веб-панель

Панель доступна на `http://localhost:8080` после запуска бота. Порт можно изменить через переменную окружения `PORT`.

Функционал:

- **Статус** — текущее состояние бота, аккаунт, аптайм, версия, количество загруженных модулей
- **Модули** — полный список модулей с кнопками загрузки/выгрузки/перезагрузки, тегами состояния, количеством строк и аддонов
- **Автозагрузка** — переключатели автозапуска для каждого модуля (сохраняется в `scripts/autostart.json`)
- **Логи** — логи в реальном времени с автообновлением, цветовая маркировка по уровням (INFO, WARNING, ERROR)
- **Команды** — справочник всех доступных команд

API-эндпоинты:

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/status` | GET | Статус бота, аптайм, список модулей |
| `/api/logs` | GET | Последние 100 записей логов |
| `/api/scripts` | GET | Список всех модулей с метаданными |
| `/api/scripts/load/<name>` | POST | Загрузить модуль |
| `/api/scripts/unload/<name>` | POST | Выгрузить модуль |
| `/api/scripts/reload/<name>` | POST | Перезагрузить модуль |
| `/api/commands` | GET | Список всех команд |
| `/api/autostart` | GET | Текущая конфигурация автозагрузки |
| `/api/autostart/<name>` | POST | Переключить автозагрузку модуля |

## Структура проекта

```
main.py              — точка входа, встроенные команды, запуск бота
config.py            — конфигурация (env vars, прокси, пути)
loader.py            — загрузчик модулей (load/unload/reload, автозагрузка, аддоны)
web.py               — Flask веб-панель + REST API
templates/index.html — фронтенд дашборда
scripts/             — директория модулей
  _utils.py          — общие утилиты (cmd(), safe_edit())
  autostart.json     — конфигурация автозагрузки
  admin/             — модерация чатов
  antimat/           — фильтр мата
  autofire/          — автоответы
  catart/            — кошачьи арты
  crypto/            — криптовалюты
  ping/              — пинг
  notes/             — заметки
  predictions/       — предсказания
  premium_emoji/     — премиум эмодзи
  subtitles/         — субтитры
  translator/        — переводчик
    addons/          — языковые аддоны (ru, uk, be, fr, zh, de)
  weather/           — погода
  yandex_music/      — Яндекс Музыка
  ai_chat/           — AI ассистент
installer/           — Windows-установщик (.exe)
  main.py            — GUI (tkinter, catppuccin-тема)
  build.bat          — сборка через PyInstaller
  background.png     — обои для установщика
logs/                — логи бота (DEBUG.log)
.env                 — конфигурация (API_ID, API_HASH и т.д.)
```
